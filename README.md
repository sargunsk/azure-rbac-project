# Project 1: RBAC Access Control – Azure Storage Account

## 🧩 Overview
This project demonstrates Azure RBAC by assigning access roles to an Azure Storage Account. It uses a test Entra ID user to simulate least-privilege access to resources at different scopes.

## ✅ Objectives
- Create Azure Storage Account in resource group
- Create Entra ID test user
- Assign RBAC roles (Reader, Blob Contributor) at different scopes
- Observe access permissions and inheritance

## 💡 Skills Gained
- Microsoft Entra ID (Azure AD) user creation
- IAM Role Assignment
- Resource group & resource-level RBAC
- Scoped access control in Azure

## 🔧 Tools Used
- Azure Portal
- Microsoft Entra ID (Azure AD)
- Storage Accounts
- IAM (Access Control)
